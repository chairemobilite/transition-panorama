# backend

## Commands

Run from this folder, with `yarn <command>`.

| Command         | What it does                                                   |
| --------------- | -------------------------------------------------------------- |
| `build`         | Builds the server.                                             |
| `check`         | Runs every check, the tests and the build.                     |
| `check:format`  | Checks the formatting.                                         |
| `check:lint`    | Checks the linting.                                            |
| `codegen`       | Regenerates the generated code. See [Regenerate](#regenerate). |
| `dev`           | Runs the server for development.                               |
| `fix`           | Fixes what can be fixed automatically.                         |
| `fix:format`    | Fixes the formatting.                                          |
| `fix:lint`      | Fixes the linting.                                             |
| `start`         | Runs the built server.                                         |
| `test`          | Runs the tests.                                                |
| `test:coverage` | Runs the tests and reports the code they cover.                |

## Transition API

The client, types and Zod schemas for [Transition](https://github.com/chairemobilite/transition)'s API are
generated by [Orval](https://orval.dev) from Transition's OpenAPI spec into
[../../packages/transition-client/src/generated/](../../packages/transition-client/src/generated/).

Do not edit the generated files: regenerate them instead, e.g. when Transition's API changes.

### Regenerate

1. Serve Transition's OpenAPI spec on http://localhost:4321
2. Generate the code:

    ```sh
    yarn codegen
    ```
