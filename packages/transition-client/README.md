# transition-client

A client for [Transition](https://github.com/chairemobilite/transition)'s API.

## Commands

Run from this folder, with `yarn <command>`.

| Command         | What it does                                                   |
| --------------- | -------------------------------------------------------------- |
| `check`         | Runs every check and the tests, then type-checks.              |
| `check:format`  | Checks the formatting.                                         |
| `check:lint`    | Checks the linting.                                            |
| `codegen`       | Regenerates the generated code. See [Regenerate](#regenerate). |
| `fix`           | Fixes what can be fixed automatically.                         |
| `fix:format`    | Fixes the formatting.                                          |
| `fix:lint`      | Fixes the linting.                                             |
| `test`          | Runs the tests.                                                |
| `test:coverage` | Runs the tests and reports the code they cover.                |

## Generated code

The client, types and Zod schemas for Transition's API are generated by [Orval](https://orval.dev) from
Transition's OpenAPI spec into [./src/generated/](./src/generated/).

Do not edit the generated files: regenerate them instead, e.g. when Transition's API changes.

### Regenerate

1. Serve Transition's OpenAPI spec on http://localhost:4321
2. Generate the code:

    ```sh
    yarn codegen
    ```
